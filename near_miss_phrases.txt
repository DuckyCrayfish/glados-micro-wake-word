# Training negatives: everyday phrases that sit near "okay GLaDOS" (oh-KAY GLAD-ohs).
# The notebook turns these into TTS clips and trains on them as "not the wake word".
#
# One phrase per line. Blank lines and # comments are ignored, except that a header
# like "# --- Name ---" starts a group (only used for reading the file; the notebook
# ignores groups). Plain text, not phonemes: Piper/espeak reads these like English.
#
# A trailing "*N" gives a phrase N times the usual share of the clips (default 1). The
# closest sound-alikes get more: bare "okay" (the first half of the wake word) *4, and
# "okay glad ..." and the "-dose/-loss/-glass" endings *2. The notebook also says each
# phrase with the same mix of punctuation the wake word prompts use ("?", "!", "." and
# "okay, ..."), so intonation can't tell the wake word from a near-miss.
#
# Phrases the model is TESTED on live in near_miss_holdout.txt and must never be
# copied in here, or the check stops measuring anything.
#
# Deliberately left out: "hey GLaDOS" and "GLaDOS" on their own. Whether those
# should trigger is a product decision, not a sound-alike.
